## About

I'm an Information Technology student at NIT Srinagar interested in software engineering, machine learning, and backend development.

I enjoy understanding how systems work, experimenting with technologies, and building projects that solve practical problems. Most of my learning comes from implementing ideas, debugging them, and improving the result over time.

Currently, I'm focusing on:

- Machine learning and time-series forecasting
- Backend development and API design
- Data structures and algorithms in JAVA
- Building and improving web applications

## Projects

### TutorNestJK

A platform focused on connecting students with tutors in Jammu and Kashmir.

- **Technologies:** React, Firebase, Tailwind CSS
- **Live application:** [tutornestjk.vercel.app](https://tutornestjk.vercel.app)

### Digital Signal Encoder and Decoder

A Java project implementing digital line-coding schemes, their decoders, signal visualization, and Pulse Code Modulation.

- **Technologies:** Java, Swing, AWT
- **Repository:** [ITT036-Digital-Encoder](https://github.com/bhar7av/ITT036-Digital-Encoder)

A machine-learning project exploring forecasting methods for sequential data.

- **Technologies:** Python, Pandas, NumPy, scikit-learn
